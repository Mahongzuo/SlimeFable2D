# 露团 · 苔光森林

一个以软体史莱姆为主角的单关横版冒险。所有森林图形由代码绘制，无付费素材或图片生成 API 依赖。

## 第二版角色升级

441 个粒子（分身各 220/221 个），1.25 单位轮廓采样、2 倍动态画布；加入行走弹性振荡、出窄缝自动回收与回弹。

空格支持二段跳；C / Tab 切换，1 / 2 直选，左上按钮或直接点击角色也能选择分身。靠墙后 W / 上箭头攀爬，S / 下箭头下滑，空格蹬墙，反方向离墙。每团独立记录跳跃次数。

浅水升级为受冲击驱动的传播波、抛物线水滴、回落扰动、泡沫及水下光纹。S 可下潜。仍为波面模型与喷溅粒子的组合，并非完整双相 PBF 水体。

新增验证：`node tests/browser-refinements.mjs`，截图与结果保存到 `output/v2-*.png` 和 `output/refinements-results.json`。

## 运行

```sh
npm install
npm run dev -- --port 5173
```

打开 http://127.0.0.1:5173 。生产构建：`npm run build`，预览：`npm run preview`。

## 操作

| 按键 | 动作 |
| --- | --- |
| A / D 或 ← / → | 移动 |
| Space | 跳跃，按住略高 |
| S / ↓ | 降低凝聚力、挤压钻缝 |
| Q | 分裂成两团 |
| Tab | 切换当前控制的分身 |
| E | 靠近且无遮挡时合并 |
| R | 回到最近检查点 |
| Esc | 暂停 |
| 反引号 | 粒子与性能调试层 |

路线：草甸 → 三级石阶 → 树根窄缝 → 浅水湾 → 双踏板石门 → 树洞。两团分别站在踏板上可永久开门；到终点前合并成一团。晨露收集为可选探索目标。

## 实现说明

- TypeScript + Vite + Phaser。硬件 WebGL 优先，软件显卡和无 WebGL 环境自动使用 Canvas。
- 441 个质量粒子，固定 120 Hz，空间哈希邻域，四次 PBF 密度约束迭代；叠加凝聚和 XSPH 黏性。分裂不增减粒子。
- Marching squares 从粒子标量场重建连续轮廓，附加厚度渐变、高光、气泡、表情。不是预制动画或缩放椭圆。
- 地形逐粒子投影；窄缝高度 26 世界像素。碰撞、状态和绘制相互独立。
- 水池为浮力/阻力区域和受角色影响的程序波纹，**不是独立 PBF 水体**。折射为半透明与厚度着色表现，未实现真实屏幕空间折射。当前属于可玩技术演示，非完整双相流体模拟。
- 森林、植被、蘑菇与 UI 均为原创程序美术。Google 字体可选，网络不可用时使用系统中文字体。音效为用户主动开启的本地生成风声。
- 桌面键盘体验为主要目标；小屏幕会保持画面比例，但尚无触屏操纵按钮。

## 验证

```sh
npm test
npm run build
npx playwright install chromium
node tests/browser.mjs
node tests/browser-route.mjs
node tests/performance.mjs
```

浏览器测试需先启动 5173 开发服务器。`tests/browser-route.mjs` 只使用玩家按键从起点走到终点，不传送角色、不改内部状态。截图与结果在 `output/`。

物理回归覆盖：静置稳定、地面碰撞、移动跳跃、分裂质量、隔墙合并限制、分身接地减速、跳跃宽限隔离、长短跳、整团穿过真实窄缝、跃出水池、踏板门锁存与检查点恢复。

## 目录

`src/physics.ts` 求解器；`src/level.ts` 地形和机关；`src/game.ts` 固定步长与操作；`src/art.ts` 场景绘画；`src/slime-view.ts` 连续表面；`src/main.ts` Phaser 和 DOM 集成。
