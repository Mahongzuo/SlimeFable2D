# 五关生态与 Toy 实施记录

基线：539a166；工作分支：codex/living-world-toy。
用户已批准五关生态、3–6 分钟短局、8000 内容分＋2000 速度分、一关一榜及编辑器兼容计划。

## 工作划分

1. 计分、永久旅行记录、Toy 适配器与隔离测试。
2. 数据化生态内容与运行时、五关地图和现有游戏循环集成。
3. 可视化、输入、HUD、图鉴和结算/榜单。
4. 编辑器新增内容支持与旧地图迁移。
5. 集成回归、浏览器截图、正常输入游玩和发布构建。

## 接口及决策

- 使用当前干净工作区中的专用分支，保留用户刚提交的基线；不自动推送或发布。
- 计分及 Toy 模块与游戏渲染解耦，父任务负责 Adventure/HUD 接入。
- 生态对象以稳定 ID 关联事件、平台与奖励，局内状态不写回地图定义。
- 收藏永久记录与本局分数分开，通关后继续游览不会改变已冻结成绩。
- 正式地图之外的编辑器覆盖、试玩和测试局无上榜资格。
- SDK 无后端验签能力，客户端校验不宣称严格防作弊。
