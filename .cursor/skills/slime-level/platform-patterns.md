# 横版冒险 · 可复用地图模式

给史莱姆寓言空岛关用。品质标杆仍是第一章；这里只补浮岛、叠层和水池，避免再把「画出来的岛」当成整块实心。

来源压缩：Celeste / Mario 的教学四步（[Tadeas Jun](https://www.tadeasjun.com/blog/2d-level-design/)）、先锁跳跃再摆台（[Solana Garden](https://solana.garden/guides/game-puzzle-platformer-design-explained/)）、视线与环线（Metroidvania 布局讨论）。手感数字用本项目现有 hop / 攀爬，不要为了对齐外站去改物理。

## 碰撞不是画

`base` 只放脚站的那一层：甲板 `h` 约 24–36，`solid.y` = 台面。

空岛甲板用**正侧视岛体条**三段切（`kit/slab.ts` 的 `paintSlab`）：生图时要求「侧立面、顶面不可见、顶边一条直线、纯白底」，宽岛 / 薄台各一条。代码里左右端盖不拉伸、中段镜像平铺，顶边 = `solid.y`，左右 = `x` / `x+w`，`gapBelowDeck` 裁掉会盖住下层的悬垂。`oneWay` 台用薄条，实心甲板用宽条。禁止 3/4 立方体、等距圆盘或俯视岛图（`plateau-*` / `step-*` / `isle-*` 那类）拉满碰撞。`h<=22` 的桥贴侧视绳桥图。神殿、天穹门、祭坛、风车、晶体、支撑石柱只做点状 dressing（`paintProp` / `paintColumn`），不进 solid。程序 `paintDeck` 只做图未加载时的兜底。

厚 AABB（`h>80` 且实心）的底面就是天花板。从下跳会顶死，看起来像「顶部被挡」。

## 从下接近

叠层浮台必须满足其一：

- `oneWay:true`（本项目物理已支持：只在从上落下时落地）
- 或薄到跳弧能从侧面绕过

短壁只填「下层顶 → 上层底」的间隙，宽约岛岩厚度（~24px），顶面埋进上层甲板。不要把短壁顶面留成半空站台。能 hop（≤200）就不要壁。

禁止通天柱、禁止用柱子把别的岛切成孤岛。

## 水只画一次

`waters[]` / `level.water` 的矩形同时是：

- 能沉、能跃的判定
- `drawPool` 的盆

不要岛图里画一整湖，再叠一层椭圆水膜。岸是薄甲板，中间挖盆，水面略低于岸。盆底可以有薄 solid，让人能踩。

## 先锁跳跃再摆台

二段跳、攀爬、合并按现有手感。摆台前用 hop ≤200 串起来。宽阶 ≥320，小地图才看得出楼梯，不要只靠 24px 壁当主路。

教学四步（一关里每种新动作走一遍）：

1. 安全见过（浅滩看得见、掉下去不罚关）
2. 第一次用（沉、跃、爬、合并）
3. 加难（更高一截台阶）
4. 和旧能力组合（湖后再爬，爬完再合并进门）

## 看得见下一步

不对称比镜像好看。岔路牌和终点要在镜头里，不要只画在小地图。装饰让开主路和登顶通道。
